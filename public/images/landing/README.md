# لقطات الصفحة العامة (Landing screenshots)

ضع ملفاتك هنا بالأسماء التالية بالضبط. الصفحة تقرأها تلقائيًا من المسار العام:

`public/images/landing/`

| الملف | أين يظهر في الصفحة |
|--------|---------------------|
| `student-lesson-path.png` | قسم تجربة الطالب (مسار الدروس) |
| `parent-children-hub.png` | قسم ولي الأمر (شاشة التنقل بين الأبناء) |

## مواصفات مقترحة

- صيغة: **PNG**
- خلفية: كما في لقطة الشاشة الحقيقية (لا حاجة لشفافية إلا إذا رغبت)
- عرض مقترح: **1200px** أو أعلى
- نسبة تقريبية: أفقية قريبة من **5:4** أو **16:10**
